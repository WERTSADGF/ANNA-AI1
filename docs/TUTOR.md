# ANNA AI Tutor Foundation

## Teaching Identity

ANNA should teach like a smart personal friend and tutor.

The default approach is:

Simple first
-> deeper explanation
-> technical detail when useful

## Teaching Cycle

UNDERSTAND GOAL
-> DETERMINE LEVEL
-> DEFINE SCOPE
-> PREREQUISITES
-> ROADMAP
-> CONCEPT
-> SIMPLE EXPLANATION
-> EXAMPLE
-> ANALOGY
-> PRACTICAL APPLICATION
-> QUESTION
-> USER ANSWER
-> EVALUATE
-> CORRECT
-> PRACTICE
-> NEXT CONCEPT

## Learning Profile

The foundation tracks:

- Preferred explanation style
- Preferred pace
- Preferred language
- Current level by subject
- Strong areas
- Weak areas
- Difficult concepts
- Common mistakes
- Revision topics
- Completed topics
- Progress by topic

## Progress

Progress is based on evidence such as:

- Answers attempted
- Correct answers
- Topic practice
- Revision state
- Completed lessons
- Detected knowledge gaps

The system must not falsely claim mastery.

## When the Owner Says "I Don't Understand"

The tutor foundation tracks explanation attempts.

The implementation can choose a different explanation strategy instead of blindly repeating the same explanation.

Future layers will provide the actual language/model-generated:

- Simpler wording
- Different examples
- Analogies
- Step-by-step breakdowns
- Practical scenarios
- Alternative perspectives

## Current Scope

Implemented:

- Learning profile
- Level assessment foundation
- Curriculum / roadmap foundation
- Lesson state
- Question cycle
- Feedback
- Progress tracking
- Knowledge-gap detection
- Explanation planning
- Tutor engine
- Tests

Not implemented yet:

- Real AI-generated teaching content
- Adaptive model-driven assessment
- Long-term learning-memory synchronization
- File-based course teaching
- Research-backed lessons
- Interactive UI
- Voice teaching
- Spaced-repetition scheduler
- Formal examinations

## Phase 8 Chat Integration

The tutor foundation is now connected to `ChatService`.

Integrated lifecycle:

START TUTOR
-> ROADMAP
-> START LESSON
-> TEACH LESSON
-> QUESTION
-> EVALUATE ANSWER
-> PROGRESS
-> KNOWLEDGE GAP DETECTION
-> COMPLETE / REVISION

`ChatService` owns a tutor engine and learning session for its lifetime.

The teaching request receives structured tutor guidance containing:
- Subject/topic
- Difficulty
- Simple-first explanation requirement
- Example requirement
- Analogy requirement
- Practical-application requirement
- Technical-detail level
- Response language

Current limitations remain:
- Teaching content is generated by the configured chat provider.
- The current default provider is deterministic/mock-backed.
- Answer correctness is supplied to the tutor engine as a boolean; model-driven assessment is not yet implemented.
- Learning profile persistence across application restarts is not yet implemented.
- Spaced repetition, formal examinations, research-backed lessons, and UI/voice teaching remain future work.
