# ANNA AI Language Foundation

## Supported Conversation Modes

- English
- Malayalam
- Manglish
- Malayalam + English mixed conversation

## Decision Priority

1. Explicit user language request
2. Current conversation language
3. Stored user preference
4. Previous conversation context
5. Default language

## Current Capabilities

The foundation can:

- Detect Malayalam script
- Detect common Manglish markers
- Detect English
- Detect Malayalam + English mixed input
- Detect explicit language requests
- Resolve a response-language decision
- Preserve language context

## Important Limitation

This is a language-routing foundation.

It is not:

- Full translation
- Full linguistic analysis
- Malayalam grammar correction
- Speech recognition
- Text-to-speech
- Regional Malayalam voice synthesis
- Semantic code-switching optimization

Voice is a later core phase.

## Provider Independence

Language routing is kept separate from AI model providers and voice providers.
